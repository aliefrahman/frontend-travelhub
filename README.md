Ini adalah proyek [Next.js](https://nextjs.org) yang diinisialisasi menggunakan [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Memulai

Pertama, jalankan server pengembangan:

```bash
npm run dev
# atau
yarn dev
# atau
pnpm dev
# atau
bun dev
```

Buka [http://localhost:3000](http://localhost:3000) dengan peramban Anda untuk melihat hasilnya.

Anda dapat mulai mengedit halaman dengan mengubah `app/page.js`. Halaman akan diperbarui secara otomatis saat Anda menyimpan perubahan berkas tersebut.

Proyek ini menggunakan [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) untuk mengoptimalkan dan memuat [Geist](https://vercel.com/font) secara otomatis, sebuah rumpun font baru dari Vercel.
